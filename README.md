# hr-agent-team · 企业招聘数字员工团队

> 基于大模型的多智能体招聘应用 —— 一支由 **5 名"数字员工"组成的 AI 招聘团队**，端到端接管整段招聘业务流程。

## 简介

本项目是一款基于大模型的多智能体招聘应用，打造一支由 **5 名"数字员工"组成的 AI 招聘团队**：

- **招聘分析师** —— 需求澄清与岗位画像
- **简历猎手** —— 渠道搜索与简历筛选
- **面试官** —— 结构化模拟面试
- **测评背调员** —— 能力测评与背景调查
- **Offer 与入职管家** —— Offer 生成与入职规划

用户只需给出一句模糊的招聘诉求（如"招个会做数据的人"），整个团队即可自主协作，端到端完成 **需求澄清 → 岗位描述生成 → 简历筛选 → 模拟面试 → 测评背调 → Offer 生成 → 入职规划** 的完整招聘闭环，交付需求澄清报告、简历打分表、面试纪要、测评报告、Offer 草案、入职计划等 **13 类可直接验收的工作成果**（报告 / 表格 / 网页）。

系统基于 **DeepSeek Harness** 多智能体开发框架构建，通过自研的 **DESP（数字员工技能协议）** 统一各数字员工间的接口与风格规范，支持任务自主规划、真实工具调用、共享记忆与关键节点人工确认，让招聘从"一问一答"变成由 AI 数字员工**接管一整段真实业务流程**。

## 面向群体

- **中小企业 HR 与招聘负责人**：缺乏专职招聘团队，招聘环节多、重复劳动重，负担不起全套专业 HR 系统；
- **业务部门负责人**：需要把模糊的用人诉求，快速变成可执行、可推进的完整招聘方案；
- **人力资源服务与就业机构**：需要批量、标准化、可追溯地处理大量招聘事务。

## 开发背景

1. **行业趋势**：AI 正从"对话式助手"迈向"自主执行"的智能体时代，业界呼唤能真正交付工作成果的"数字员工"——本项目正是对这一趋势的产品化探索。

2. **真实痛点**：一次招聘横跨需求分析、简历筛选、面试、测评、Offer、入职 6 大环节，中小企业既缺人手也缺标准，招聘质量难保证、过程难沉淀、成果难验收。

3. **技术条件**：大模型的工具调用与多智能体编排能力已趋成熟。本项目基于多智能体开发框架，以真实可运行的 5-Agent 协同系统验证"人人可拥有的 AI 数字员工"这一命题，并自研技能协议解决多智能体间的耦合与风格一致性问题。
